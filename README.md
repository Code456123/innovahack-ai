# 📖 About

VeriGen AI is an **Autonomous Multi-Agent Research & Fact Verification System** developed for **InnovaHack 2026 – Domain 3: Generative AI**.

Instead of relying on a single Large Language Model (LLM), VeriGen AI coordinates multiple specialised AI agents that independently research, verify, analyse contradictions, and generate trustworthy, citation-backed reports with confidence scores.

Our goal is to reduce AI hallucinations and improve transparency by validating every important claim against multiple trusted sources before presenting it to the user.

---

# 🚨 Problem Statement

Generative AI models are powerful research assistants but often produce **hallucinations**, unsupported claims, and misinformation.

Users frequently receive answers that appear convincing but lack reliable evidence or citations, making them unsuitable for research, education, healthcare, finance, and other critical domains.

The challenge is to design a system where multiple AI agents collaborate to:

- Research information
- Cross-verify claims
- Detect contradictions
- Identify hallucinations
- Provide reliable citations
- Generate confidence scores

---

# 💡 Our Solution

VeriGen AI introduces a **Multi-Agent Verification Pipeline** where specialised AI agents work collaboratively instead of relying on a single AI model.

Each agent performs one dedicated task:

- Research trusted sources
- Verify extracted claims
- Detect contradictions
- Identify hallucinations
- Calculate confidence scores
- Generate a final evidence-backed report

This collaborative workflow significantly improves the reliability and transparency of AI-generated information.

# 🛠️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/your-repository.git
```

---

## 2️⃣ Go Inside Project

```bash
cd your-repository
```

---

## 3️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

## 4️⃣ Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

## 5️⃣ Configure Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

SUPABASE_URL=your_supabase_url

SUPABASE_ANON_KEY=your_supabase_key

LYZER_API_KEY=your_lyzer_api_key

JWT_SECRET=your_secret
```

---

## 6️⃣ Run Backend

```bash
npm run dev
```

---

## 7️⃣ Run Frontend

```bash
cd ../frontend

npm run dev
```

---

## 8️⃣ Open Browser

```
http://localhost:3000
```
